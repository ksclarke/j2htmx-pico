
# j2htmx-pico

An opinionated Java to HTML generator that supports HTMX (v4) and Pico CSS (v2). It's based on the [j2html](https://j2html.com) project (which, to my knowledge, is
[no longer active](https://www.reddit.com/r/java/comments/mu3ptp/j2html_is_looking_for_a_maintainer/)). Since it's a fork, it continues the versioning of the original project.

j2htmx-pico serves a narrow, specialized use case and is best suited for simple, small-scale HTML interfaces rather than large, complex websites. While it offers type-safe, Java-native 
performance, it achieves this at the cost of abandoning the Separation of Concerns design pattern that helps make larger websites maintainable.

## Getting Started

To use j2htmx-pico, you need to include it as a dependency in your Maven-built project.

### Add the Dependency to your POM:

```xml
<dependency>
    <groupId>info.freelibrary</groupId>
    <artifactId>j2htmx-pico</artifactId>
    <version>2.0.0-SNAPSHOT</version>
</dependency>
```

Then, you are ready to start using it in your code.
